# Тесты маршрутизации: <профиль|*> <хост[=ip]> <ожидаемая политика>

# Запуск: tools/check.sh   (или route_sim.py --tests tests/routes.txt conf/sr_home.conf conf/sr_away.conf)
# Правила с IP/GEOIP симулятор проверяет только если задан IP (host=ip); GEOIP не моделируется,

# Часть ожиданий сверена с реальным приложением через Config -> Test Rule (2026-10-16, v2.2.92).
